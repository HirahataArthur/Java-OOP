## 📌 About the Repository

The goal of this repository is to consolidate core object-oriented principles through practical exercises. It moves beyond basic control structures to focus on designing modular, reusable, and structured code using Java.

### Key Concepts Covered
* **Classes & Objects:** Attributes, methods, constructors, and instantiation
* **Encapsulation:** Access modifiers (`private`, `protected`, `public`), getters, and setters
* **Inheritance:** Class hierarchies, `super` keyword, and code reusability
* **Polymorphism:** Method overloading and method overriding (`@Override`)
* **Abstraction:** Abstract classes and interfaces
